앱에서 내 계정 탈퇴하기

내 계정 탈퇴 기능이 제공되는 최신 앱에서 별도의 이메일 요청 없이 현재 로그인한 본인 마매새겨 계정의 삭제를 요청할 수 있어요.

  1. 설정 → 계정과 백업 → 내 계정 탈퇴를 열어요.
  2. 화면에 표시된 계정과 기록·사진의 삭제 범위를 확인해요. 필요한 자료는 삭제 전에 내 기록 내보내기로 보관해 주세요.
  3. 삭제 범위와 복원할 수 없다는 점을 확인한 뒤 체크하고 탈퇴 요청하기를 눌러요.
  4. 서버가 접수를 확인하면 이 기기의 해당 계정 기록을 정리하고 로그아웃해요. 기기 정리가 실패한 경우에는 복구 안내에서 다시 확인할 수 있어요.

다른 이용자의 계정을 삭제하는 기능이 아니에요. 앱의 접수 화면은 서버의 최종 삭제 완료를 뜻하지 않아요. 요청 확인·처리와 남기는 최소 기록의 기준은 아래에서 확인해 주세요.

로그아웃한 뒤에도 앱의 삭제 처리 확인에서 서버의 처리 상태를 확인할 수 있어요. 서버가 최종 완료를 확인한 경우에만 완료로 표시하며, 접수나 이 기기의 정리 완료를 서버 완료로 대신 표시하지 않아요. 자동 완료 이메일은 발송하지 않아요. 서버 확인 기간이 지났거나 확인이 계속 실패하면 운영팀에 문의해 주세요.

앱 내 기능이 없는 이전 버전이나 앱에 접근할 수 없는 경우에는 이메일로도 요청할 수 있어요.

1. 요청 확인과 처리

ELIM :O SOFT 운영팀이 요청을 확인하고, 본인 계정인지와 삭제할 범위를 확인한 뒤 서버 자료를 처리해요. 본인 확인에 필요한 최소 정보만 요청하며, 비밀번호·인증번호·신분증 전체나 일기 원문을 이메일로 보내지 마세요.

앱에서 본인 계정의 삭제를 요청하면 서버가 접수된 요청을 차례로 처리해요. 현재 로그인한 계정에만 요청할 수 있으며, 요청 후에는 해당 계정의 서버 백업과 복원을 제한해요. 이메일로 요청한 경우에는 운영팀이 본인 계정인지와 요청 범위를 확인한 뒤 처리해요.

이메일로 접수한 삭제·권리행사 요청은 운영팀이 지체 없이 확인하고 필요한 조치를 하며, 이메일 요청을 받은 날부터 10일 이내에 처리 결과를 알려드리는 기준을 적용해요. 이 기준은 앱이 삭제 완료 이메일을 자동 발송한다는 뜻은 아니에요. 추가 본인 확인이나 처리가 필요하면 필요한 사항과 이유·현재 진행 상황을 신속히 안내해요. 결과에 이의가 있으면 같은 이메일로 재검토를 요청할 수 있어요.

요청 접수와 삭제 완료는 서로 달라요. 문제가 남아 있으면 완료로 안내하지 않아요. 아래의 45일은 처리 후 필요한 최소 기록의 최대 보유기간이며, 삭제를 45일까지 미루거나 안내만으로 처리기한을 연장한다는 뜻은 아니에요.

2. 삭제되는 범위

내 계정 탈퇴: 본인 마매새겨 계정 정보와 이 계정에 연결된 서버의 학습 백업·일기·기도·묵상·감정·사진을 삭제해요. 특정 기록이나 사진만 삭제하려면 해당 범위를 알려주세요. 처리된 서버 자료는 이용자가 다시 복원할 수 없어요.

개인 기록 삭제·동의 철회: 계정을 유지하면서 일기·묵상·사진만 서버에서 삭제하거나 백업 관련 동의를 철회하려면 요청 범위에 적어 주세요. 동의 철회와 서버 기록 삭제 기능이 제공되는 버전에서는 설정 → 계정과 백업에서 같은 이름의 버튼을 누르거나 백업 체크를 해제한 뒤 범위를 확인하고 요청할 수 있어요. 확인하면 이 계정으로 모든 기기에서 백업한 일기·묵상·감정·기도·사진을 서버에서 삭제 접수해요. 학습 진행도·로그인 계정·기기 기록은 유지하며, 서버 삭제 완료 전에는 개인 기록을 다시 백업할 수 없어요. 이전 버전의 백업 중단 내역은 새 삭제 요청으로 자동 전환하지 않아요. 운영팀이 이메일 요청도 확인해 필요한 조치를 하고 결과를 안내해요.

기기에 남은 자료: 이메일로 서버 삭제를 요청해도 휴대폰에만 저장한 기록과 다른 기기의 사본이 함께 지워지지는 않아요. 앱 삭제나 로그아웃만으로 서버 자료가 삭제되는 것도 아니에요. 기기의 자료 정리가 필요하면 요청에 함께 적어 주세요. 계정 이메일을 확인하기 위해 재설치하거나 기존 기록을 지울 필요는 없어요.

앱 내 삭제 기능이 제공되는 최신 버전에서는 서버가 접수를 확인한 뒤 이 기기의 해당 계정 기록과 그 계정으로 이관한 기기 원본을 정리하고 로그아웃해요. 다른 계정이나 이관하지 않은 게스트 기록은 대상에서 제외해요. 기기 정리를 마치지 못하면 확인된 접수 내역을 유지하고 정리를 다시 시도해요. 접수 확인을 받지 못했을 때는 기기 자료를 삭제하지 않고 상태 확인을 안내해요. 앱의 ‘삭제 요청을 접수했어요’ 화면은 서버에서 최종 삭제까지 완료됐다는 안내가 아니에요.

별도로 남는 자료: Google·Apple 자체 계정, 휴대폰 사진 앱의 원본, 직접 내보낸 파일과 다른 기기의 자료는 마매새겨 서버 계정 삭제 대상이 아니에요. 필요한 사본은 삭제 전에 따로 보관해 주세요.

3. 남기는 최소 삭제 기록

과거 백업을 복원했을 때 삭제한 자료가 다시 나타나지 않도록, 계정·사진을 구분하는 최소 식별 정보와 삭제 종류·자료 버전·삭제 시각을 앱 자료와 분리된 비공개 저장소에 보관해요. 이 기록에는 이름·이메일·일기·묵상 본문이나 사진 파일을 넣지 않아요.

앱 서버의 최소 완료 증빙은 별도 삭제 기록 저장을 확인한 뒤 최초 실제 완료 후 30일 기준으로 정리하고, 별도 최소 삭제 기록은 최초로 실제 삭제 처리가 완료된 시각부터 최대 45일 이내에 파기하도록 구성했어요. 재확인·재시도·원장 이관으로 이 시각을 늦추지 않아요. 기록을 없애기 전에 삭제한 자료가 들어 있는 과거 복구 사본도 정리해요.

내려받은 삭제 기록의 임시 운영 사본은 만든 때부터 최대 14일, 어느 경우에도 최초 실제 삭제 완료 후 45일을 넘겨 보관하지 않아요. 전환 전 Git 기록·이력과 기존 사본도 원래 보유기한에 따라 관리하고 정리해요. 필요한 최소 사본의 보유기간이 남아 있는 것과 파기 기한을 넘기는 것은 구분해요.

별도 삭제 기록의 정기 자동 파기를 설정하고 초기 실행을 확인했어요. 실패나 사본 확인이 필요한 경우에는 완료로 안내하지 않고 원래 기한을 유지하여 확인·재시도해요. 접수된 본인 계정·서버 자료의 삭제 처리와 처리 후 필요한 최소 기록의 자동 파기는 서로 다른 절차예요.

삭제 처리 확인 정보: 기기에 만든 보호된 확인 번호로 로그인 없이 해당 요청의 처리 상태만 확인해요. 서버에는 확인 번호의 SHA-256 해시만 저장하며, 완료 요청의 해시는 앱 서버의 최소 완료 증빙과 함께 최초 실제 완료 후 30일 기준으로 정리해요. 완료되지 않은 접수의 확인 해시는 최초 접수 후 45일에 만료돼요. 이 만료는 삭제 완료를 뜻하지 않으며 삭제 작업 자체를 취소하지 않아요. 확인 응답에는 계정 식별자·이메일·글·사진이 없어요.

기기의 확인 번호는 계정 로그인 정보와 분리해 보호하며, 서버 완료와 기기 정리가 모두 확인되면 번호를 제거해요. 어떤 경우에도 기기 최초 저장 후 45일에 확인 번호를 만료시키고 다음 앱 실행·접근 시 정리해요. 앱을 실행하지 않는 동안 기기 저장소의 물리 파기를 정확한 시각에 보장하는 것은 아니에요. 계정 식별자 없는 기기의 처리 상태·시각 표시도 같은 45일 기준이나 이용자의 확인 기록 지우기로 정리해요.

후속 문의와 처리 내용 확인에 필요한 이메일·최소 본인 확인 내역도 처리 완료일로부터 최대 45일 이내에 파기하는 기준을 적용해요. 불필요하게 받은 자료나 확인이 끝난 임시자료는 더 일찍 파기해요. 운영자가 보유한 자료의 기준이며, 메일함에서 영구 삭제하고 내려받은 첨부·사본도 정리해요. 이용자의 메일함이나 공급자가 별도로 유지하는 내부 복구 사본까지 같은 기간에 없어짐을 뜻하지는 않아요. 공급자 잔존 보유 범위는 개인정보처리방침에서 별도로 안내해요.

제공되는 앱 버전에 따른 삭제 안내

내 계정 탈퇴 기능이 제공되는 최신 앱의 본인 계정 삭제 요청과 앱 없이 가능한 이메일 요청을 함께 안내해요. 앱에서는 보호된 확인 번호로 최종 완료를 확인하며 자동 완료 이메일은 보내지 않아요. 이메일 민원에는 10일 이내 결과 안내 기준을, 필요한 최소 삭제 기록에는 최초 완료 후 최대 45일 보유 기준을 적용해요. 접수와 최종 완료는 구분하며, 자료 정리나 본인 확인이 필요한 경우 이유와 진행 상황을 안내해요. 처리 위치는 개인정보처리방침에서 확인할 수 있어요.
