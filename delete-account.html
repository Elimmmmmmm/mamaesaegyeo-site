1. 요청 확인과 처리

ELIM :O SOFT 운영팀이 요청을 확인하고, 본인 계정인지와 삭제할 범위를 확인한 뒤 서버 자료를 처리해요. 본인 확인에 필요한 최소 정보만 요청하며, 비밀번호·인증번호·신분증 전체나 일기 원문을 이메일로 보내지 마세요.

앱 안에서 삭제 기능을 이용할 수 없는 경우에도 이메일로 요청할 수 있어요. 운영팀이 본인 계정인지와 요청 범위를 확인한 뒤 삭제를 처리해요.

삭제 요청은 지체 없이 확인하고 필요한 조치를 하며, 요청을 받은 날부터 10일 이내에 처리 결과를 알려드리는 기준을 적용해요. 추가 본인 확인이나 처리가 필요하면 필요한 사항과 이유·현재 진행 상황을 신속히 안내해요. 결과에 이의가 있으면 같은 이메일로 재검토를 요청할 수 있어요.

요청 접수와 삭제 완료는 서로 달라요. 문제가 남아 있으면 완료로 안내하지 않아요. 아래의 45일은 처리 후 필요한 최소 기록의 최대 보유기간이며, 삭제를 45일까지 미루거나 안내만으로 처리기한을 연장한다는 뜻은 아니에요.

2. 삭제되는 범위

전체 계정 삭제: 마매새겨의 로그인 계정 정보와 서버에 보관한 학습 백업·일기·기도·묵상·감정·사진을 삭제해요. 특정 기록이나 사진만 삭제하려면 해당 범위를 알려주세요. 처리된 서버 자료는 이용자가 다시 복원할 수 없어요.

기기에 남은 자료: 이메일로 서버 삭제를 요청해도 휴대폰에만 저장한 기록과 다른 기기의 사본이 함께 지워지지는 않아요. 앱 삭제나 로그아웃만으로 서버 자료가 삭제되는 것도 아니에요. 기기의 자료 정리가 필요하면 요청에 함께 적어 주세요. 계정 이메일을 확인하기 위해 재설치하거나 기존 기록을 지울 필요는 없어요.

앱 내 삭제 기능이 제공되는 버전에서는 서버가 접수를 확인한 뒤 이 기기의 해당 계정 기록과 계정으로 이관한 기기 원본을 정리하고 로그아웃하도록 준비했어요. 다른 계정이나 이관하지 않은 기기 기록은 대상에서 제외해요.

별도로 남는 자료: Google·Apple 자체 계정, 휴대폰 사진 앱의 원본, 직접 내보낸 파일과 다른 기기의 자료는 마매새겨 서버 계정 삭제 대상이 아니에요. 필요한 사본은 삭제 전에 따로 보관해 주세요.

3. 남기는 최소 삭제 기록

과거 백업을 복원했을 때 삭제한 자료가 다시 나타나지 않도록, 계정·사진을 구분하는 최소 식별 정보와 삭제 종류·자료 버전·삭제 시각을 비공개 삭제 기록으로 보관해요. 이 기록에는 이름·이메일·일기·묵상 본문이나 사진 파일을 넣지 않아요.

최소 삭제 기록은 삭제 완료 확인일로부터 최대 45일 이내에 파기하는 기준으로 준비했어요. 기록을 없애기 전에 삭제한 자료가 들어 있는 과거 복구 사본도 정리해요.

후속 문의와 처리 내용 확인에 필요한 이메일·최소 본인 확인 내역도 처리 완료일로부터 최대 45일 이내에 파기하는 기준으로 준비했어요. 불필요하게 받은 자료나 확인이 끝난 임시자료는 더 일찍 파기해요. 운영자가 보유한 자료의 기준이며, 메일함에서 영구 삭제하고 내려받은 첨부·사본도 정리해요. 이용자의 메일함이나 공급자가 별도로 유지하는 내부 복구 사본까지 같은 기간에 없어짐을 뜻하지는 않아요. 공급자 잔존 보유 범위는 개인정보처리방침에서 별도로 안내해요.
