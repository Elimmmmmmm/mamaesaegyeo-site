1. 적용 범위와 운영자

ELIM :O SOFT는 마매새겨를 운영합니다. 이 안내는 모바일 앱의 학습·개인 기록, 선택적 계정 백업, 광고와 소개 사이트에서 처리하는 정보를 설명합니다. 계정 기능과 광고의 제공 범위는 실제 제공되는 앱 버전에 따라 달라집니다.

현재 앱은 테스트 단계이며 실제 수익 광고는 활성화하지 않았습니다. 계정 기능이 제공되는 버전에서 이용자가 선택한 로그인·백업 범위에 이 방침이 적용됩니다. Apple 로그인은 실제 iPhone·iPad에서의 최종 시험이 남아 있습니다. 소개 사이트에서는 앱에 로그인하거나 기록을 업로드하지 않습니다.

3. 선택과 동의 철회

앱에서 백업과 동의 선택하기

  1. 설정에서 계정과 백업을 열어요.
  2. 일기·묵상·사진도 백업하기를 선택하고 안내를 읽어요.
  3. [선택] 일기·묵상·사진의 수집·이용과 서버 백업, [선택] 글·사진에 포함될 수 있는 종교적 신념·건강 등 민감정보의 백업·복원 목적 처리를 각각 확인해요.
  4. 두 항목에 동의한 뒤 동의하고 백업하기를 선택해요.

동의하지 않거나 취소해도 기기에서 학습과 기록을 이용할 수 있어요. 현재 백업 선택은 일기·묵상·사진 범주를 켜거나 끄는 방식이며, 개별 글을 골라 전송하는 기능은 제공하지 않습니다.

로그인만으로 일기·묵상·사진이 서버로 전송되지는 않습니다. 이 자료에 종교적 신념이나 건강 등 민감한 내용이 포함될 수 있으므로 수집·이용 동의와 별도의 민감정보 처리 동의를 받습니다. 서버에서 동의 저장을 확인한 뒤 개인 기록 전송을 허용하고, 동의한 계정·버전·목적·시각과 철회 내역을 필요한 범위에서 기록합니다.

동의 철회와 서버 기록 삭제 기능이 제공되는 버전에서는 백업 체크를 해제하거나 같은 이름의 버튼을 누르고, 삭제 범위를 확인한 뒤 요청합니다. 확인하면 새 개인 기록 전송을 중지하고 모든 기기에서 이 계정으로 백업한 일기·묵상·감정·기도·사진을 서버에서 삭제 접수합니다. 삭제 접수와 최종 완료는 구분하며, 처리 중에는 개인 기록 재백업을 제한합니다. 학습 진행도·로그인 계정·기기 기록은 유지합니다. 기존 자료의 삭제나 개인정보 처리 동의 철회는 elim.soho@gmail.com으로 요청할 수 있습니다. 탈퇴하지 않고 내 계정의 일기·묵상·사진만 처리하도록 요청할 수도 있습니다. 운영팀은 본인과 요청 범위를 확인한 뒤 해당 자료의 파기 등 필요한 조치를 하고 결과를 안내합니다. 이전 버전에서 백업을 껐던 내역을 새 서버 삭제 요청으로 자동 전환하지 않습니다. 별도로 삭제를 확인하고 요청해야 하며, 앱에서 서버 삭제가 완료됐음을 확인하기 전에는 완료로 안내하지 않습니다.

계정 삭제·개인 기록 삭제·동의 철회의 요청 방법은 계정 삭제 요청 페이지에서 확인할 수 있습니다. 로그아웃·앱 삭제·Google 또는 Apple 접근 철회만으로 마매새겨 서버 자료가 삭제되지는 않습니다.

4. 어린이 이용과 광고

로그인·계정 백업은 만 14세 이상에게 제공합니다. 만 14세 미만은 로그인 없이 이용하며 학습 기록·일기·묵상·사진을 기기에만 저장합니다. 공통 연령 확인을 적용한 버전(빌드 13부터)은 처음 사용할 때 중립적인 숫자 입력으로 만 나이를 확인하고, 계정 이용 범주와 광고 연령 범주를 함께 정합니다. 입력한 정확한 나이와 생년월일은 보관하지 않습니다. 연령 범주와 확인일은 기기에만 보관하고, 서버에는 계정 기능을 이용할 수 있다는 범주만 확인합니다. 이전 확인 정보와 일치하지 않거나 저장을 확인할 수 없으면 로그인·서버 전송과 광고 요청을 허용하지 않습니다. 이전 버전의 서로 다른 연령 선택은 중립적인 입력으로 다시 확인합니다. 이 자기신고 절차가 실제 나이를 증명하는 본인 인증을 뜻하지는 않습니다.

광고가 제공되는 Android·iOS 버전의 현재 연결은 테스트 광고입니다. 광고 요청에 일반 잠재고객(G) 등급·어린이 대상 설정·비맞춤 광고를 적용하고 광고 ID 및 퍼스트파티 ID 사용을 제한합니다. iOS에서는 앱 추적 투명성(ATT) 권한을 요청하지 않고, 앱이 IDFA를 직접 읽거나 광고 요청에 넣지 않으며 퍼스트파티 광고 ID 사용을 끄도록 구성합니다. 연령을 확인하지 못하면 광고를 요청하지 않습니다. 비맞춤 광고에서도 IP 주소·대략적인 위치·앱 또는 개발자 범위의 기기 식별자·광고 상호작용·충돌 및 성능 진단 정보의 처리가 발생할 수 있습니다. 이 설정만으로 광고 SDK의 정보 수집 전체가 중단된다고 안내하지 않습니다. 개인 글·사진·성구별 기록을 광고 요청에 포함하지 않습니다.

앱 설정의 개인정보·광고 설정에서 현재 안내와 연령 설정을 확인할 수 있습니다. Google의 광고 개인정보 선택 화면이 제공되는 경우 같은 화면에서 선택을 변경할 수 있습니다. 실제 광고를 도입하거나 처리 범위가 달라지면 안내와 필요한 선택 절차를 갱신합니다.

이 기기의 학습·개인 기록이용자가 기록을 삭제하거나 앱 저장 공간을 정리할 때까지 기기에 남습니다. 앱 삭제·기기 초기화·운영체제의 정리 방식에 따라 제거 범위가 달라질 수 있습니다.
계정·서버 학습 백업·동의한 글과 사진계정과 백업 기능 제공에 필요한 동안 보관하고, 계정 또는 해당 자료의 삭제 요청을 확인한 뒤 정리합니다. 백업 기능 중단과 개인정보 처리 동의 철회는 구분하며, 동의 철회 시 해당 동의로 처리하던 자료에 필요한 파기 조치를 합니다.
로그인 연결·인증 정보로그인 유지와 계정 기능에 필요한 동안 보관합니다. 해당 계정 삭제 처리에는 인증 정보와 연결 정리를 포함하며, Apple 로그인을 제공하는 버전에서는 관련 권한 해제도 처리합니다.
문의·본인 확인 자료문의 응답과 권리행사 처리에 필요한 최소한의 자료만 사용합니다. 처리 내용 확인과 후속 문의 대응을 위해 필요한 이메일·최소 확인 내역은 처리 완료일로부터 최대 45일 이내에 운영자가 보유한 사본을 파기하는 기준을 적용합니다. 불필요하게 받은 신분증·비밀번호 등의 자료나 확인이 끝난 임시자료는 더 일찍 파기합니다.
최소 삭제 처리 기록과거 백업의 삭제 재적용을 위해 최소 식별 정보만 별도로 보관합니다. 이름·이메일·일기·묵상 내용·사진 파일은 이 기록에 넣지 않습니다. 앱 서버의 최소 완료 증빙은 별도 삭제 기록 저장을 확인한 뒤 최초 실제 완료 후 30일 기준으로 정리하고, 별도 삭제 기록은 최초로 실제 삭제 처리가 완료된 시각부터 최대 45일 이내에 파기하도록 구성했습니다. 재확인·재시도·원장 이관으로 이 시각을 늦추지 않습니다. 기록을 없애기 전에 삭제한 자료가 포함된 과거 복구 사본도 정리하여, 삭제한 자료가 다시 서비스되지 않도록 합니다.
삭제 처리 확인 정보앱이 만든 보호된 확인 번호의 SHA-256 해시를 서버에 보관하고 처리 중·완료 상태와 최초 실제 완료 시각만 조회하도록 합니다. 원본 확인 번호는 서버에 저장하지 않으며, 확인 응답에는 계정 식별자·이메일·본문·사진을 넣지 않습니다. 완료 요청의 확인 해시는 앱 서버의 최소 완료 증빙 정리와 연동하여 최초 실제 완료 후 30일 기준으로 정리하고, 완료되지 않은 접수의 해시는 최초 접수 후 45일에 만료합니다. 확인 해시 만료가 삭제 완료나 삭제 작업 취소를 뜻하지는 않습니다.
기기의 삭제 확인 번호계정 로그인 정보와 분리된 보호 저장소에 두며 서버 완료와 기기 정리를 확인하면 원본 번호를 제거합니다. 최초 기기 저장 후 최대 45일 뒤에는 확인 번호가 만료되며 다음 앱 실행·접근 시 정리합니다. 앱을 실행하지 않는 동안 기기 저장소의 물리 파기를 정확한 시각에 보장하지 않습니다. 계정 식별자 없이 남기는 기기의 처리 상태·시각 표시도 같은 45일 기준 또는 이용자의 확인 기록 지우기로 정리합니다.
삭제 기록의 임시 운영 사본삭제 처리와 복구 검증에 필요한 사본만 제한적으로 보관합니다. 내려받은 삭제 기록 사본은 만든 때부터 최대 14일, 어느 경우에도 최초 실제 삭제 완료 후 45일을 넘겨 보관하지 않습니다. 기존 사본도 원래 사건과 보유기한을 유지하며, 복사·검증을 다시 했다는 이유로 기한을 늦추지 않습니다.
운영 로그·복구 사본현재 무료 서버의 고객 조회 가능 API·DB 로그는 1일, 인증 감사 로그는 1시간 기준입니다. 별도 인증 감사 기록의 추가 DB 저장은 꺼져 있습니다. 고객용 예약 프로젝트 백업은 포함되지 않으며 독립 운영 백업은 구성하지 않았습니다. 공급자 내부 사본과 운영자가 보유한 시험 사본은 별도로 확인·정리합니다. 이 설정이 모든 내부 보안 기록의 동일한 파기기간을 뜻하지는 않습니다.

파기 방법

문의 이메일은 처리 완료 후 필요한 최소 내역만 관리하고 최대 45일 안에 운영 메일함에서 영구 삭제하며, 내려받은 첨부·사본도 제거하는 기준입니다. 휴지통으로 옮기는 것만으로 파기 완료로 안내하지 않습니다. 운영자의 45일 기준은 공급자 내부 복구 사본까지 같은 기간에 없어짐을 뜻하지는 않습니다. Google이 별도로 처리하는 사본은 Google의 보관·삭제 안내를 함께 확인할 수 있습니다.

이용자 계정에 연결된 데이터베이스 행을 삭제하고 사진 파일을 저장소에서 제거하며, 해당 인증 정보와 계정 연결도 정리합니다. 앱 내 삭제 처리가 제공되는 버전에서는 접수 확인 후 해당 계정의 이 기기 기록과 로그인 상태도 정리합니다. 이메일 요청으로 다른 기기의 기록이나 이용자가 내보낸 파일까지 원격 삭제하지는 않습니다. 종이 자료를 보관하게 되는 경우에는 내용을 재구성할 수 없도록 파기합니다.

일반 이용자가 삭제 완료된 서버 자료를 다시 복원하는 기능은 제공하지 않습니다. 운영 복구 사본이 존재하는 경우에는 삭제 기록과 현재 동의 상태를 확인하여 삭제한 자료나 동의를 철회한 개인 기록이 다시 서비스되지 않도록 관리합니다. 전자 자료의 삭제 완료, 복구 사본의 보유 종료, 최소 삭제 기록의 파기는 구분하여 안내합니다.

별도 삭제 기록의 정기 자동 파기를 설정하고 초기 실행을 확인했습니다. 처리 실패나 사본 확인이 필요한 상태는 완료로 표시하지 않고 원래 기한을 유지하여 확인·재시도합니다. 운영팀은 사본의 보유기한과 자동 처리 결과를 점검합니다. 이 자동 파기는 앱의 내 계정 자동 탈퇴 기능과 별개입니다.

45일 보유 기준: 45일은 삭제를 기다리는 기간이 아니라 처리 후 필요한 최소 기록의 최대 보유기간입니다. 기한이 남고 목적이 필요한 최소 사본은 해당 기간 안에서 관리하며, 모든 사본이 현재 즉시 파기됐다는 뜻은 아닙니다. 자동 파기의 초기 검증을 전체 보유기한 경과나 향후 모든 실행의 성공으로 안내하지 않습니다.

7. 권리행사와 계정 삭제

정보의 열람·정정·삭제·처리정지와 동의 철회를 요청할 수 있습니다. 본인 계정 확인에 필요한 최소한의 정보를 확인하며 비밀번호·인증번호·신분증 전체를 이메일로 요청하지 않습니다.
