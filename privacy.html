마매새겨 : 계시록 암송

공개 전 확인본

계정 공개·자동 삭제·광고 운영을 준비하는 문서입니다. 담당자 표기와 실제 서버·기기 검증을 마친 뒤 공개하며, 현재 배포된 앱의 기능 완료를 뜻하지 않습니다.

1. 적용 범위와 운영자

ELIM :O SOFT는 마매새겨를 운영합니다. 이 안내는 모바일 앱의 학습·개인 기록, 선택적 계정 백업, 광고와 소개 사이트에서 처리하는 정보를 설명합니다. 계정 기능과 광고의 제공 범위는 실제 제공되는 앱 버전에 따라 달라집니다.

현재 계정 저장은 승인된 테스트 계정으로 확인 중이고 실제 수익 광고는 활성화하지 않았습니다. 공개 전 확인본의 시행일·책임자 표기와 아래 일반 공개 기능은 최종 점검 후 확정합니다.

3. 선택과 동의 철회

계정 로그인만으로 기기의 모든 글과 사진이 서버에 올라가지는 않습니다. 일기·묵상·사진 백업은 선택 사항이며, 종교적 신념이나 건강 등 민감한 내용이 포함될 수 있어 별도의 민감정보 처리 동의도 받도록 준비합니다. 거부해도 기기에서 작성할 수 있습니다.

백업을 끄면 이후 해당 자료의 업로드를 중단합니다. 이미 서버에 저장한 자료는 자동으로 삭제되지 않습니다. 이전 자료 삭제는 계정 삭제 또는 아래 연락처로 요청할 수 있습니다. 로그아웃·앱 삭제·Google 또는 Apple 접근 철회는 서버 자료 삭제와 다릅니다.

4. 어린이 이용과 광고

어린이를 포함하여 기기에서 학습할 수 있습니다. 보호자 동의 기능을 제공하기 전의 일반 공개 계정 범위는 공개 전에 확정합니다. 계정 연령 확인과 광고 연령 설정은 별도로 다룹니다.

현재 광고 구현은 모든 확인된 광고 연령 구간에 일반 잠재고객(G) 등급·아동 보호 태그·비개인화 요청을 적용합니다. 연령을 확인하지 못하면 광고를 요청하지 않습니다. Android 광고 ID 권한은 사용하지 않습니다. 설정과 필터만으로 모든 광고의 내용에 문제가 없다고 보장하지 않으며, 발견한 광고는 차단 관리로 조치합니다.

광고는 학습 결과를 확인하는 구간에만 표시하도록 준비했습니다. 첫 학습 실행에는 광고를 면제하며, 이후 성구 학습을 5회 완료할 때마다 광고를 표시할 기회가 됩니다. 재학습도 포함하고 횟수는 기기 재실행 후에도 유지합니다. 광고를 불러오지 못하면 학습은 계속할 수 있고 나중에 몰아서 표시하지 않습니다.

소개 사이트에는 별도의 방문 분석이나 광고 도구를 넣지 않습니다. 제공자별 해외 처리 국가·이전의 법적 근거와 보유기간은 공개 전 확인 항목입니다.

6. 보유와 삭제

  • 기기 기록은 이용자가 삭제하거나 앱 저장 공간을 지울 때까지 남을 수 있습니다.
  • 계정과 서버 백업·사진은 이용자의 계정 삭제 요청이 처리될 때까지 보관합니다. 더 이상 필요한 목적이 없어진 자료는 지체 없이 삭제합니다.
  • 삭제 요청·처리 상태와 원장은 삭제된 정보가 과거 백업에서 다시 나타나지 않도록 필요한 최소 범위로 관리합니다. 독립 재해 복구 사본의 실제 운영 주기와 원장 보유기간은 공개 전에 확정합니다.
  • 문의 자료는 처리 목적이 끝나면 삭제합니다. 법령상 별도 보관 의무가 있는 경우 해당 근거와 기간에 따라 분리하여 보관합니다.

독립 DB·사진 재해 복구 백업은 아직 운영 설정을 완료하지 않았습니다. 계정 백업이 모든 장애에서 복원을 보장하는 기능이라고 안내하지 않습니다.

7. 권리행사와 계정 삭제

정보의 열람·정정·삭제·처리정지와 동의 철회를 요청할 수 있습니다. 본인 계정 확인에 필요한 최소한의 정보를 확인하며 비밀번호·인증번호·신분증 전체를 이메일로 요청하지 않습니다.

앱을 설치하지 않고 계정 삭제 요청하는 방법도 제공합니다. 자동 삭제 처리가 제공되는 버전에서는 설정의 ‘계정과 백업’에서 계정 삭제를 요청할 수 있습니다.

8. 보호 조치와 변경

로그인한 이용자는 자신의 자료에만 접근하도록 권한을 제한하고 사진 저장소를 비공개로 운영합니다. 전송 암호화, 입력 형식·사진 크기·파일 검증, 요청 제한과 별도 관리자 인증을 적용합니다. 비밀번호나 관리자 비밀키를 앱에 넣지 않습니다.

개인정보 처리 내용이 달라지면 실제 기능과 일치하도록 방침을 갱신하고 필요한 동의와 안내를 제공합니다. 이 문서는 공개 전 확인본이며, 확정된 시행일과 변경 이력은 공개 시 명시합니다.
